# Compact and motion-preference evidence

Every direction and intensity has `reduced/` and `off/` captures at 1280×720,
`uiScale: 1.25`, Noto Sans / Noto Sans Mono fallback fonts. `off/` also sets
`lowEffects: true`; `reduced/` retains normal surface effects. Each contains idle,
focused-app, Command Core and Settings stills plus a source/PNG hash manifest.

The compact footer reserves only the space below the existing shortcut buttons,
so the creative identity stays legible without covering Command, Navigator,
Systems or Settings. Command input and the volume service assertion run before
Settings is opened. App/window data are explicit Hyprland fixtures; these are real
shell renders, not real browser screenshots. Motion gating and service behavior
are checked by the verification runs; still images alone do not establish timing.
